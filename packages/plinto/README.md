# plinto

The unscoped name for [`@plinto/astro`](https://github.com/maxmart/plinto/tree/main/packages/astro).
Every entry point is mirrored: `plinto/integration`, `plinto/config`,
`plinto/middleware`, `plinto/preview`, `plinto/lib/ops` and so on are the
same modules as under `@plinto/astro/…`. Stylesheets and Astro components
resolve straight to the scoped package.

See the repository for the adopter-facing setup guide.
